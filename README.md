# PM Skills — Compact Edition

A single Claude skill (`product-manager-skills/`) bundling 77 product management skills in **134 files**, under Claude's 200-file upload limit.

- `product-manager-skills/SKILL.md` — router with an index of all skills
- `product-manager-skills/references/` — one file per skill (77)
- `product-manager-skills/templates/` — fill-in templates (56)
- `product-manager-skills.zip` — ready to upload (Claude → Settings → Capabilities → Skills → Upload)

Worked examples and helper scripts from the full library are omitted to fit the limit.
